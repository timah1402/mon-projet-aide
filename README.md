# SenFrais — Mobile App

A multi-service mobile app built with React Native and Expo that brings together a marketplace, deliveries and rentals in one place, with a dedicated space for each type of user.

## User roles and features

| Role | What they can do |
|------|------------------|
| **Customer** | Browse the marketplace, order products, track orders and transactions |
| **Seller** | Manage a shop and inventory, publish products, see sales analytics |
| **Sender** | Request a delivery, follow the driver live on a map, manage payment methods |
| **Driver** | See available missions, navigate, track earnings and delivery history, upload documents |
| **Host** | Publish listings, manage reservation requests and calendar, read reviews |
| **Tenant** | Book listings, manage reservations and payments, leave reviews |
| **Admin** | Validate drivers and hosts, manage users and disputes, monitor IoT alerts |

Shared features: in-app chat, notifications, invoices, disputes, reviews and profile settings.

## Tech stack

React Native · Expo (Expo Router) · TypeScript · React Navigation · React Native Maps · Google Places Autocomplete · Tailwind (twrnc) · AsyncStorage

## Getting started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go (Android/iOS), or press `a` / `i` to open an emulator.
